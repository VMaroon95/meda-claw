# Project Portfolio — Varun Meda

## 1. meda-claw (v1.0.1)
- **Status:** Live on GitHub
- **Purpose:** Forensic security and risk scoring for AI-generated code. Scans repos (local or remote), scores governance posture 0–100, blocks unsafe commits via git hooks, and auto-remediates findings.
- **Tech:** Python, AST Analysis, Git Hooks, Click CLI
- **Links:** [GitHub](https://github.com/VMaroon95/meda-claw)
